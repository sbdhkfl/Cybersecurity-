# Contributing

Thanks for helping improve SentinelKit.

1. Open an issue describing the proposed change or bug.
2. Keep each tool focused, documented, and safe by default.
3. Add automated tests for new parsing and analysis logic.
4. Avoid collecting, transmitting, or storing secrets.
5. Document platform limitations and required permissions.
6. Run the test suite with `python -m pytest` before submitting a pull request.

Contributions must remain defensive and authorized-use oriented. Do not submit malware, credential theft, covert access, destructive payloads, or retaliation features.

By submitting a contribution, you agree that it may be distributed under this repository's MIT License.
