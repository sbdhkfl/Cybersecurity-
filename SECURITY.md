# Security Policy

## Scope

SentinelKit is intended for defensive use on systems and networks you own or have explicit permission to assess.

## Reporting a vulnerability

Please do not publish sensitive exploit details in a public issue. Contact the repository maintainer privately through GitHub's available security reporting feature, if enabled. Include the affected version, impact, and safe reproduction details.

## Project boundaries

This project will not accept features designed for malware deployment, credential theft, covert persistence, evasion, destructive actions, unauthorized access, or retaliation against other devices.

## Supported use

Use the tools only for lawful administration, education, and authorized security testing. You are responsible for obtaining permission before testing any system.
